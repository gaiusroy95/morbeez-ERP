# Documentation

This folder holds documentation that lives with the code: ADRs and
operational runbooks. The governing design documents (Technical
Constitution, System Architecture, Technology Stack, Domain Model, Event
Catalog, Accounting Engine, Cost Allocation Engine, Inventory Engine,
Workflow States, Production Database) are maintained as the team's shared
Artifacts, linked below — this repo does not duplicate them.

- `constitution/` — a local copy point for the ratified Technical Constitution
- `architecture/` — a local copy point for the System Architecture and
  Technology Stack documents
- `domain-model/` — a local copy point for the Domain Model and Event Catalog
- `adr/` — Architecture Decision Records amending any governing document
  (Constitution, Article IX.2)
- `runbooks/` — operational runbooks (incident response, backup/restore,
  deploy rollback — Constitution VII.8)
